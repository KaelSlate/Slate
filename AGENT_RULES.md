# Правила для агентов (Agent Rules)

Эти правила обязательны для всех агентов, работающих с проектом Slate. Любое отступление от них **недопустимо**. Проект создается на бескомпромиссном уровне качества (Apple-level, премиальный дизайн и архитектура). Выбирайте лучшее из возможных решений во всем бесконечном пространстве вариантов.

## 1. Архитектура и База Данных (Under the hood)
* **SQLite / sqlcipher**: Используем локальную базу данных как единственный источник правды. Это дает нам мгновенный отклик и эталонный уровень производительности. 
* **Никакого Облака в Dart напрямую**: Код на Dart НИКОГДА не вызывает Supabase напрямую. Принцип: UI (Flutter) -> Локальная память (Rust) -> Локальный SQLite -> Фоновая асинхронная синхронизация с облаком.

## 2. Безопасность FFI и Компиляция Rust
* **Транспорт (Zero-Copy)**: Никакого JSON! Rust и Dart общаются исключительно через нативные `#[repr(C)]` структуры и указатели. Это дает нам заветные 120 FPS.
* **Правило Компиляции (КРИТИЧЕСКИ ВАЖНО)**: Каждый раз после изменения кода Rust и выполнения `cargo build --release` в папке `native`, ты ОБЯЗАН скопировать файл `native/target/release/slate_core.dll` в корень проекта Flutter (`slate_core.dll`). Забудешь — Dart загрузит старую DLL, шаблоны памяти не совпадут, и приложение умрет без логов (Access Violation). (Примечание: учитывайте актуальное имя DLL, сейчас это slate_core.dll).
* **Утечки памяти (Сверхважно!)**: Памятью управляет протокол Caller-Frees. Если Rust выделяет память, Dart берет данные и в блоке finally ОБЯЗАН вызвать функцию очистки (например, `_ffiFreeHourSlotList!(list)`).
* **Политика Zero .unwrap()**: Код Rust НИКОГДА не должен падать (Panic). Паника в потоке Rust моментально убивает приложение Flutter.

## 3. Запуск Приложения
* Запуск должен быть исключительно в профиле: `flutter run --profile -d windows`. Обычный `flutter run -d windows` — запрещен!

## 4. UI/UX и Дизайн (Apple-level)
* **Бескомпромиссная планка**: Везде в приложении всё должно быть как под капотом, так и визуально на наивысшем уровне — лучший вариант из всей бесконечности возможных. Liquid glass, микроанимации, премиальные цвета. 
* **Правило Курсоров**: Никакого меняющегося курсора в приложении! Везде только обычная стрелочка (`SystemMouseCursors.basic`), никаких "лапок" при наведении. Это дает ощущение нативного, монолитного премиум-приложения.
* **ИСКЛЮЧЕНИЕ для Курсоров**: Только поля ввода текста (`TextField`) используют `SystemMouseCursors.text` (I-beam курсор). Это стандарт нативных приложений (Apple, Linear, Raycast). Применимо к Command Pill, inline title editing и т.д.

Не нарушайте эти правила. Вы — часть команды, создающей шедевр.
