# Media playbook — как снимать Slate профессионально

Личный плейбук Kael. Всё бесплатное. Написано под конкретную машину: **Windows 10, экран 1366×768, работа через Parsec.**

---

## 0. Твоё главное ограничение — и как из него сделать преимущество

**Экран 1366×768.** Это мало. Для соцсетей комфортная база — 1920×1080. Отсюда железное правило:

> **Никогда не снимай весь экран. Снимай только окно или ещё лучше — кусок окна.**

Полноэкранный скрин 1366×768 в Твиттере выглядит мыльно и дёшево. А плотный кадр окна 1100×650, снятый 1:1 без растягивания, выглядит **резко и дорого**. В ленте Твиттера картинка всё равно ужимается до ~600px шириной — твоего разрешения хватает с запасом, если не растягивать.

**НЕ МЕНЯЙ РАЗРЕШЕНИЕ ЭКРАНА, чтобы «снять получше».** Ты работаешь через Parsec, смена режима дисплея однажды уже убила сессию и стоила перезагрузки. Никакой скриншот этого не стоит.

**И плюс, которого ты не замечаешь:** твоя главная фича — пилюля 600×57. Она **крошечная**. Твой лучший кадр физически не требует большого экрана. Пилюля крупным планом поверх чужого приложения — это плотный, тесный, кинематографичный кадр. Ограничение работает на тебя.

## 1. Инструменты — поставить один раз (всё бесплатно)

**ShareX** — скриншоты окна с тенью и прозрачностью, обрезка, ресайз, GIF.
Главный инструмент, 90% работы делается им.
`winget install ShareX.ShareX`

**OBS Studio** — запись видео.
`winget install OBSProject.OBSStudio`

**ScreenToGif** — превращает видео в GIF, чистит лишние кадры.
`winget install NickeManarin.ScreenToGif`

**Carnac** — показывает нажатые клавиши прямо на экране.
`winget install Code52.Carnac`

> **Carnac — секретный ингредиент.** Slate управляется с клавиатуры,
> и без визуализатора зритель видит «что-то само появилось» вместо
> «а, он нажал Alt+Space». Это разница между «непонятно» и «хочу так же».

**Carnac — твой секретный ингредиент.** Slate управляется с клавиатуры, и зритель не понимает, что происходит, если не видит `Alt+Space`. Визуализатор клавиш превращает «что-то само появилось» в «а, он нажал сочетание». Это разница между «непонятно» и «хочу так же».

## 2. Подготовка сцены — как фотограф готовит студию

Делается один раз, потом просто повторяешь.

### Windows
- **Скрыть значки рабочего стола:** ПКМ по столу → Вид → снять «Отображать значки рабочего стола»
- **Обои:** тёмные однотонные или мягкий градиент. Никаких фото, котиков, аниме. Обои — фон, а не сюжет
- **Focus Assist ON:** Параметры → Система → Фокусировка внимания → «Только будильники». Иначе посреди записи вылезет уведомление Telegram с чьим-то именем — и кадр в помойку
- **Закрыть всё лишнее.** В кадр не должно попасть ни одного окна, которого ты не планировал

### Slate
Это важнее всего остального, вместе взятого.

- **Задачи должны быть настоящими.** Не «Task 1», не «тест», не «ааа». Живой день живого человека: `Созвон с Димой`, `Забрать посылку`, `Тренировка`, `Дочитать главу`
- **Задачи должны рассказывать историю.** Пусть по дню видно, что у человека есть работа, спорт и личное. Зритель за 2 секунды считывает «это про мою жизнь»
- **Время должно быть человеческим.** Не 03:00. Утро и вечер рабочего дня
- **День не пустой и не забитый.** 4–6 задач. Пусто = «продукт мёртвый», забито = «ужас, стресс»
- **Убери демо-задачи**, если они ещё висят (трей → «Очистить примеры»)

> Правило фотографа: **предмет съёмки — это контент, а не интерфейс.** Люди смотрят на задачи, а не на скругления углов. Плохие задачи = плохой кадр, какой бы красивый ни был UI.

## 3. Скриншоты — рецепт ShareX

ShareX у тебя на русском. Ниже русские названия пунктов, а в скобках —
английские, потому что перевод местами кривой и проще найти по оригиналу.
Если совсем путает — язык переключается в
**Настройки приложения → Общие → Язык** (Application settings → General → Language).

### Настройка, делается один раз

**Шаг 1. Прозрачность и тень окна.**
Главное окно ShareX → слева **«Настройки задач»** (Task settings) →
вкладка **«Захват»** (Capture) → поставить галочку
**«Захват с прозрачностью»** (Capture with transparency).

У тебя Windows 10 — здесь это работает корректно, тень окна
захватывается целиком. (На Windows 11 тень больше и обрезается,
но тебя это не касается.)

**Шаг 2. Своя тень.**
Там же → **«Настройки задач»** → **«Эффекты изображения»**
(Image effects) → **«Настроить эффекты»** (Configure effects) →
кнопка **«Добавить»** → **Drawings → Drop shadow** (Тень).

Настройки тени:
- Size (размер) — `30`
- Opacity (непрозрачность) — `60`
- Offset Y (смещение вниз) — `8`

**Шаг 3. Поля вокруг окна.**
В том же окне эффектов → **«Добавить»** → **Manipulations → Canvas** (Холст).
Поля по `60` со всех сторон.
Цвет фона — `#14100C` (твой брендовый графит) либо прозрачный.

**Шаг 4. Формат.**
**«Настройки задач»** → **«Загрузка»** → формат **PNG**. Всегда PNG,
никогда JPG — JPG замыливает текст и мелкие линии.

### Как снимать

- **Окно целиком:** `Ctrl + PrintScreen` → навести на окно Slate → клик
- **Кусок экрана:** `PrintScreen` → выделить мышью область

Получаешь окно с настоящей тенью на брендовом фоне.
Ни панели задач, ни чужих окон, ни синей полосы сверху — их физически
нет в кадре, потому что ты снимаешь окно, а не экран.

### Как обрезать и изменить размер

ShareX умеет всё сам, Paint не нужен.

Открой скриншот в редакторе: главное окно ShareX → **«Инструменты»**
(Tools) → **«Редактор изображений»** (Image editor).

- **Обрезать:** инструмент **«Обрезать изображение»** (Crop image)
- **Изменить размер:** **«Изменить размер изображения»** (Image resize) —
  вводишь точные цифры в пикселях

## 3б. Шапка для Twitter — точный рецепт

Нужен размер **1500×500** — это пропорция ровно 3:1.
Твой экран 1366×768, то есть 16:9. Значит надо **вырезать
горизонтальную полосу** и слегка увеличить.

### Цифры

1. Сними **весь экран** целиком (`PrintScreen` → выделить всё), 1366×768
2. Обрежь до **1366×455** — это уже точная пропорция 3:1
3. Увеличь до **1500×500**

Увеличение всего на 10% — глазом не видно. Это единственный способ
получить шапку с твоего разрешения без мыла.

> **Не режь маленький кусок и не растягивай его до 1500.** Увеличение
> в полтора-два раза даёт мыльный текст, и шапка сразу выглядит дёшево.

### Что должно попасть в полосу

Резать надо **по горизонтали через таймлайн** — часовая лента это
самое узнаваемое, что у тебя есть, и она читается даже в мелком виде.

Две зоны, про которые все забывают:

- **Аватарка накрывает левый нижний угол шапки.** Всё важное держи
  правее и выше центра, слева пусть будет пустой фон.
- **На телефоне шапку обрезают по бокам.** Всё осмысленное — в
  центральных 60%.

Текст и логотипы в шапку не пихай. Шапка — это атмосфера, а не плакат.

### Три кадра, которые тебе нужны

**Кадр 1 — ГЕРОЙ (самый важный).**
Пилюля поверх чужого приложения. Открой VS Code или браузер с чем-то рабочим, вызови `Alt+Space`, набери половину фразы `тренування завтра о 18` и в этот момент снимай **регион** (не окно) — так, чтобы в кадр попала пилюля и кусок того приложения снизу.

Это единственный кадр, который доказывает главное: **работает поверх всего, не надо ничего открывать.** Скриншот пилюли на пустом столе не доказывает ничего.

**Кадр 2 — день целиком.** Окно Slate, дневной вид, живые задачи, вертикальная лента часов. Это «вот как выглядит продукт».

**Кадр 3 — момент попадания.** Задача только что приземлилась на таймлайн. Хорошо работает как вторая картинка в паре «до/после».

## 4. Видео и GIF

### Что снимать — единственная сцена, которая продаёт

```
0:00  Виден VS Code / браузер. Человек работает.
0:01  Alt+Space (Carnac показывает клавиши). Пилюля выезжает снизу.
0:02  Печатается: gym tomorrow at 6pm
0:04  Enter. Пилюля исчезает.
0:05  Задача стоит на таймлайне в 18:00.
```

**Пять секунд. Всё.** Это весь твой питч. Не показывай настройки, не показывай меню, не показывай неделю и месяц. Одна мысль на одно видео — правило и фотографа, и маркетолога.

### OBS — настройки под 1366×768

- Settings → Video: **Base 1366×768, Output 1366×768, FPS 60**
  (60 fps обязательно — твоя пружинная анимация пилюли на 30 fps выглядит дёргано и убивает всё впечатление)
- Settings → Output → Recording: **Quality = Indistinguishable**, формат **mp4**, кодировщик **NVENC**, если есть видеокарта NVIDIA, иначе x264
- Source: **Display Capture** (не Window Capture — тебе нужно видеть пилюлю ПОВЕРХ другого окна, а Window Capture снимет только одно окно)
- Потом обрежешь лишнее в ScreenToGif

### Кадрирование
Снял весь экран — **обрежь до тесного кадра** вокруг пилюли и таймлайна. Панель задач, кнопки окна, пустые поля — всё вон. Тесный кадр = профессионально.

### GIF или видео?
- **GIF** — для Твиттера и Reddit. Автоплей, петля, не надо нажимать. **Всегда предпочитай GIF**, если сцена короче 8 секунд
- ScreenToGif: открыть mp4 → обрезать → удалить лишние кадры → сохранить GIF. Держи вес **под 5 МБ**, иначе Твиттер пережмёт в кашу
- **Видео** — только если сцена длиннее 10 секунд и нужен голос

### Первый кадр решает
Видео в ленте показывает первый кадр как обложку. Если первый кадр — пустой стол, никто не нажмёт. Начинай с кадра, где **уже что-то происходит**.

### Про Parsec
OBS пишет то, что происходит **на самом ПК**, а не то, что видит Parsec. Качество записи будет чистым. Но **мышь через Parsec двигается рывками** — поэтому не строй ролик вокруг движений мыши. Строй вокруг клавиатуры. Тебе повезло: твоя фича и есть клавиатурная.

## 5. Build in public — без продакшена

Ты испугался «медиапродакшена». Его нет. **95% build-in-public — это текст плюс одна картинка.** Пост пишется за две минуты с телефона.

### Формула поста, которая работает

```
[Что было сломано или что решал]
[Скриншот или GIF]
[Что понял]
```

Реальный пример из твоей же истории:

> Спент three days chasing a bug where my capture bar rendered as a
> stretched slab in the corner. Turns out a hidden window keeps its
> WS_MAXIMIZE bit, and SetWindowPos on a maximized window is silently
> swallowed. No error. My tests passed 12/12 because they checked
> rectangles, not pixels.
>
> [скриншот растянутой пилюли]
>
> Lesson: if your tests are green and the screen is wrong, your tests
> are measuring the wrong thing.

Это **не реклама**. Это история, из которой можно унести урок. За такое подписываются.

### Чего НЕ постить
- «Работаю над продуктом, скоро релиз!» — ноль информации, никому
- Голая ссылка на скачивание без контекста — читается как спам
- Скриншот без объяснения, что на нём происходит

### Что постить (у тебя этого материала на месяцы)
- Баг, который тебя мучил, и его настоящая причина
- Решение, которое ты откатил, и почему
- До/после интерфейса
- Цифра: «первый тестер», «37 просмотров на DOU»
- Вопрос к аудитории: «синхронизация с Google Calendar — нужна или это предательство идеи локальности?»

### Ритм
**2–3 поста в неделю.** Меньше — забывают, больше — ты выгораешь и бросаешь. Лучше три месяца по два поста, чем неделя по пять и тишина.

### Время публикации (Твиттер, под западную аудиторию)
Вторник–четверг, **16:00–19:00 по Киеву** = утро в США. Понедельник и пятница слабее. Выходные — мёртвая зона для техаудитории.

### Площадки по приоритету
1. **X / Twitter** — build in public живёт здесь. Хештеги `#buildinpublic`, `#indiedev`
2. **r/SideProject** — терпимы к самопиару, но сначала прочитай правила сабреддита
3. **Indie Hackers** — там любят историю, а не продукт
4. **Product Hunt / Show HN** — одноразовые выстрелы. Не трать, пока страница и продукт не готовы

## 6. Чек-лист перед каждой съёмкой

- [ ] Значки рабочего стола скрыты
- [ ] Focus Assist включён (не вылезет уведомление)
- [ ] В Slate живые задачи, не «тест»
- [ ] Время на таймлайне человеческое
- [ ] Закрыты все окна, которых не должно быть в кадре
- [ ] Carnac запущен, если снимаю клавиатурное действие
- [ ] Снимаю окно или регион, НЕ весь экран
- [ ] После съёмки: обрезал тесно, панели задач в кадре нет

## 7. Минимальная версия, если совсем нет времени

Если сил хватает только на одно действие в неделю:

1. Поставь **ShareX**
2. Настрой в нём тень (пункт 3)
3. Наполни Slate живыми задачами **один раз**
4. Раз в неделю: `Ctrl+PrintScreen` → окно → пост в Твиттер с одним абзацем о том, что чинил

Это уже build in public. Всё остальное — надстройка.
