# ЗАДАНИЕ: где в Украине раздать бета-версию десктопного приложения (актуально на 2026)

Это чисто исследовательская задача. Ничего не строй и не переписывай продукт — нужен разведанный список каналов с проверенными ссылками.

## Контекст

**Slate** — бесплатный десктопный планировщик дня для **Windows**: нативный (Rust + Flutter), полностью локальный (данные на устройстве, без облака и аккаунта), без подписки. Глобальный хоткей → выдохнул мысль текстом → парсер сам ставит её на таймлайн дня.

**Стадия:** закрытая бета. Ищу **10–15 первых тестеров**, чтобы понять, возвращаются ли люди.

**Целевая аудитория:** украинские айтишники — разработчики, дизайнеры, инди-мейкеры, студенты-технари, продуктивность-энтузиасты. Обязательно **пользователи Windows**. Вкус: Raycast / Linear / Arc.

**Бюджет на рекламу: 0 (ноль).** Платные размещения нужны только справочно, чтобы я знал цену на будущее.

## Что найти

Актуальный на 2026 год список украинских IT-сообществ, где можно заявить о проекте и найти тестеров. **Приоритет — бесплатные способы.**

**Обязательно раздели по типу — механика у них разная:**

1. **ЧАТЫ / ГРУППЫ (Telegram, Discord)** — живое общение, можно постить и/или писать участникам в ЛС. ← **ГЛАВНЫЙ ПРИОРИТЕТ, это бесплатно.**
2. **КАНАЛЫ (Telegram, broadcast)** — пишет только админ. Для них выясни: как связаться с админом, берут ли инди-проекты бесплатно (рубрики «проєкт дня», «інді», «покажи свій проєкт»), и если только платно — примерная цена.
3. **Форумы и сайты** — DOU.ua (и его разделы под пет-проекты), украинские IT-медиа, площадки для показа проектов.
4. **Facebook / LinkedIn группы**, украинские дизайнерские сообщества.
5. **Университетские и курсовые сообщества** (IT-курсы, буткемпы, студенческие IT-чаты) — там студенты-технари.

## Формат ответа

Таблица + короткая карточка по каждому пункту:

- Название + **рабочая ссылка**
- Тип (чат / канал / форум / группа)
- Примерный размер аудитории (если известен)
- Тематика (общий IT / Flutter / фронтенд / дизайн / продуктивность / город)
- **Можно ли бесплатно заявить о проекте?** (да / нет / только через админа / только в спец-рубрике) — если нашёл правила сообщества, процитируй
- Как именно действовать: постить самому / писать админу / писать участникам в ЛС
- Если платно — примерная цена размещения
- Уверенность: **подтверждено / надо проверить вручную**

В конце — **приоритетный ТОП-10 «куда идти первым»**, по каждому пункту конкретное действие.

## Требования к качеству (важно)

- **Проверяй существование ссылок поиском. Не выдумывай.** Мёртвая или несуществующая ссылка хуже, чем её отсутствие. Где не уверен — пиши прямо «надо проверить вручную».
- Ищи **актуальное на 2026** — сообщества умирают, переезжают, меняют правила.
- Учитывай и украиноязычные, и русскоязычные украинские сообщества.
- Отдельно отметь площадки, где **разрешён self-promo** или есть регулярные рубрики/треды вроде «покажи свій проєкт», «пʼятниця — самопіар», «show your side project».
- **Известная точка старта:** `https://t.me/ITUkraineNow` — это **КАНАЛ** (не чат), размещение у него, вероятно, платное. Проверь: есть ли у него связанный чат для обсуждений, и есть ли бесплатные рубрики для инди-проектов.

## Чего НЕ надо

- Не предлагать платную рекламу как основной путь (бюджет 0).
- Никакого спама, массовых рассылок, накрутки.
- Не трогать продукт, позиционирование и тексты — это уже сделано в других документах.
